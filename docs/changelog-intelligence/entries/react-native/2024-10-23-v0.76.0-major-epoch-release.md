# React Native 0.76.0 — NEW ARCHITECTURE ENABLED BY DEFAULT & React 19

- **Package**: `react-native`
- **Version**: `0.76.0`
- **Release Date**: 2024-10-23
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.76.0](https://github.com/facebook/react-native/releases/tag/v0.76.0)

## 1. Summary & Architectural Context
React Native 0.76 enables the New Architecture (Fabric + TurboModules + Bridgeless) by default for all new applications. Introduces React 19 concurrency compatibility, official W3C CSS boxShadow and filter style support, and modern React Native DevTools.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 18.18`
- **React Peer Dependency**: `18.3.1`
- **Hermes Engine**: `0.76-bundled`
- **Metro Bundler**: `^0.80.12`
- **Android Toolchain**: AGP `8.5.1` · Gradle `8.8` · Target SDK `35`
- **iOS Toolchain**: Deployment Target `iOS 15.1` · Xcode `16.0`
