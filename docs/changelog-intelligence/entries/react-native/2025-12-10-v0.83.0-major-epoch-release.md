# React Native 0.83.0 — Bridgeless TurboModule Enforcing Mode

- **Package**: `react-native`
- **Version**: `0.83.0`
- **Release Date**: 2025-12-10
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.83.0](https://github.com/facebook/react-native/releases/tag/v0.83.0)

## 1. Summary & Architectural Context
React Native 0.83 removes all legacy RCTBridge native APIs. All native modules must implement TurboModuleRegistry.getEnforcing or NitroModules.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 20.0`
- **React Peer Dependency**: `18.3.1`
- **Hermes Engine**: `0.83-bundled`
- **Metro Bundler**: `^0.84.0`
- **Android Toolchain**: AGP `8.8.1` · Gradle `8.12` · Target SDK `35`
- **iOS Toolchain**: Deployment Target `iOS 16.0` · Xcode `16.2`
