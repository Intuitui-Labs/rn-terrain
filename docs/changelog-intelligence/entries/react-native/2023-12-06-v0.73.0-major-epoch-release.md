# React Native 0.73.0 — Bridgeless Mode (Experimental), Kotlin Template & Android 14

- **Package**: `react-native`
- **Version**: `0.73.0`
- **Release Date**: 2023-12-06
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.73.0](https://github.com/facebook/react-native/releases/tag/v0.73.0)

## 1. Summary & Architectural Context
React Native 0.73 introduces experimental Bridgeless Mode (eliminating the legacy RCTBridge entirely under New Architecture), adopts Kotlin as the default Android template language, upgrades Android build toolchain to AGP 8.1, and officially deprecates Flipper.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 18.0`
- **React Peer Dependency**: `18.2.0`
- **Hermes Engine**: `0.73-bundled`
- **Metro Bundler**: `^0.80.3`
- **Android Toolchain**: AGP `8.1.4` · Gradle `8.3` · Target SDK `34`
- **iOS Toolchain**: Deployment Target `iOS 13.4` · Xcode `15.0`
