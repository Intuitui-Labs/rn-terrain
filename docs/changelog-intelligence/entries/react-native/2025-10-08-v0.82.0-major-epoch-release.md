# React Native 0.82.0 — OLD ARCHITECTURE (PAPER / BRIDGE) PERMANENT REMOVAL

- **Package**: `react-native`
- **Version**: `0.82.0`
- **Release Date**: 2025-10-08
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.82.0](https://github.com/facebook/react-native/releases/tag/v0.82.0)

## 1. Summary & Architectural Context
React Native 0.82 permanently severs the Old Architecture (Paper / Bridge). Setting newArchEnabled=false is strictly banned and triggers build/runtime failure. ViewPropTypes and ColorPropType are permanently deleted.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 20.0`
- **React Peer Dependency**: `18.3.1`
- **Hermes Engine**: `0.82-bundled`
- **Metro Bundler**: `^0.83.0`
- **Android Toolchain**: AGP `8.8.0` · Gradle `8.11.1` · Target SDK `35`
- **iOS Toolchain**: Deployment Target `iOS 16.0` · Xcode `16.2`
