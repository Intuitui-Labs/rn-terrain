# React Native 0.72.0 — Metro Symlink Support & Package Exports

- **Package**: `react-native`
- **Version**: `0.72.0`
- **Release Date**: 2023-06-21
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.72.0](https://github.com/facebook/react-native/releases/tag/v0.72.0)

## 1. Summary & Architectural Context
React Native 0.72 unlocks first-class monorepo and symlink support in Metro bundler via package exports. Upgrades bundled Hermes engine to 0.72 series and stabilizes style property handling.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 16.14`
- **React Peer Dependency**: `18.2.0`
- **Hermes Engine**: `0.72-bundled`
- **Metro Bundler**: `^0.76.7`
- **Android Toolchain**: AGP `7.4.2` · Gradle `8.0.1` · Target SDK `33`
- **iOS Toolchain**: Deployment Target `iOS 12.4` · Xcode `14.0`
