# React Native 0.75.0 — Autolinking C++ & Template Diet

- **Package**: `react-native`
- **Version**: `0.75.0`
- **Release Date**: 2024-08-14
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.75.0](https://github.com/facebook/react-native/releases/tag/v0.75.0)

## 1. Summary & Architectural Context
React Native 0.75 rewrites auto-linking in native C++ to dramatically accelerate build times on Android and iOS, reduces template binary overhead, and adopts TypeScript 5.0 as the strict floor.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 18.0`
- **React Peer Dependency**: `18.3.1`
- **Hermes Engine**: `0.75-bundled`
- **Metro Bundler**: `^0.80.9`
- **Android Toolchain**: AGP `8.3.2` · Gradle `8.8` · Target SDK `34`
- **iOS Toolchain**: Deployment Target `iOS 15.1` · Xcode `15.4`
