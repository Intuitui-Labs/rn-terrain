# React Native 0.74.0 — Yoga 3.0 & Bridgeless Default on New Architecture

- **Package**: `react-native`
- **Version**: `0.74.0`
- **Release Date**: 2024-04-22
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.74.0](https://github.com/facebook/react-native/releases/tag/v0.74.0)

## 1. Summary & Architectural Context
React Native 0.74 upgrades the layout engine to Yoga 3.0 (with breaking flex basis and rounding precision fixes), enables Bridgeless mode by default when New Architecture is active, switches on batched onLayout callbacks, and adopts Yarn 3 for the template.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 18.0`
- **React Peer Dependency**: `18.2.0`
- **Hermes Engine**: `0.74-bundled`
- **Metro Bundler**: `^0.80.8`
- **Android Toolchain**: AGP `8.2.1` · Gradle `8.6` · Target SDK `34`
- **iOS Toolchain**: Deployment Target `iOS 13.4` · Xcode `15.0`
