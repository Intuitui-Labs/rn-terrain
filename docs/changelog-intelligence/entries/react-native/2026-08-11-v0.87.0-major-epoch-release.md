# React Native 0.87.0 — Strict TypeScript API Default & SwiftPM Experimental

- **Package**: `react-native`
- **Version**: `0.87.0`
- **Release Date**: 2026-08-11
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.87.0](https://github.com/facebook/react-native/releases/tag/v0.87.0)

## 1. Summary & Architectural Context
React Native 0.87 makes source-generated strict TypeScript types the default, deprecates deep imports from react-native/Libraries/*, adopts AGP 9 / Kotlin 2.0+, and introduces experimental Swift Package Manager support.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 22.13`
- **React Peer Dependency**: `19.0.0`
- **Hermes Engine**: `v1.1-default`
- **Metro Bundler**: `^0.87.1`
- **Android Toolchain**: AGP `9.0.0` · Gradle `8.13` · Target SDK `35`
- **iOS Toolchain**: Deployment Target `iOS 16.0` · Xcode `16.2`
