# React Native 0.79.0 — Synchronous TurboModule JSI Hardening

- **Package**: `react-native`
- **Version**: `0.79.0`
- **Release Date**: 2025-04-08
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.79.0](https://github.com/facebook/react-native/releases/tag/v0.79.0)

## 1. Summary & Architectural Context
React Native 0.79 optimizes synchronous C++ TurboModule JSI calls, reducing interop latency to near-zero and eliminating event emitter memory leaks in long-running sessions.

- **Node.js**: `>= 18.18`
- **React Peer Dependency**: `18.3.1`

- **iOS Toolchain**: Deployment Target `iOS 15.1` · Xcode `16.2`
