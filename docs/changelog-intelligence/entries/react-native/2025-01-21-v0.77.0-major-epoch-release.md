# React Native 0.77.0 — Swift Template Support & CMake Modernization

- **Package**: `react-native`
- **Version**: `0.77.0`
- **Release Date**: 2025-01-21
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.77.0](https://github.com/facebook/react-native/releases/tag/v0.77.0)

## 1. Summary & Architectural Context
React Native 0.77 brings official Swift support to the iOS project template, modernizes CMake build scripts for C++ TurboModules, and adds initial Android 15 edge-to-edge support.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 18.18`
- **React Peer Dependency**: `18.3.1`
- **Hermes Engine**: `0.77-bundled`
- **Metro Bundler**: `^0.81.0`
- **Android Toolchain**: AGP `8.6.0` · Gradle `8.10` · Target SDK `35`
- **iOS Toolchain**: Deployment Target `iOS 15.1` · Xcode `16.1`
