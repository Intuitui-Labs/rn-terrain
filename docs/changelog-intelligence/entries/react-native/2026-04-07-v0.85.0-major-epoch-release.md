# React Native 0.85.0 — Static Hermes Bytecode Optimization

- **Package**: `react-native`
- **Version**: `0.85.0`
- **Release Date**: 2026-04-07
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.85.0](https://github.com/facebook/react-native/releases/tag/v0.85.0)

## 1. Summary & Architectural Context
React Native 0.85 delivers ahead-of-time bytecode optimizations in Hermes, cutting cold app start times by up to 25% on mid-tier Android devices.
