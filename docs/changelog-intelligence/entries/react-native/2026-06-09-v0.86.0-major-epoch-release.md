# React Native 0.86.0 — Android 15 Edge-to-Edge Default & Architecture Complete

- **Package**: `react-native`
- **Version**: `0.86.0`
- **Release Date**: 2026-06-09
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.86.0](https://github.com/facebook/react-native/releases/tag/v0.86.0)

## 1. Summary & Architectural Context
React Native 0.86 enforces Android 15 edge-to-edge system insets by default, stabilizes window measurement coordinates, and completes the multi-year New Architecture transition.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 22.11`
- **React Peer Dependency**: `19.0.0`
- **Hermes Engine**: `v1.0-default`
- **Metro Bundler**: `^0.86.3`
- **Android Toolchain**: AGP `8.9.1` · Gradle `8.12.1` · Target SDK `35`
- **iOS Toolchain**: Deployment Target `iOS 16.0` · Xcode `16.2`
