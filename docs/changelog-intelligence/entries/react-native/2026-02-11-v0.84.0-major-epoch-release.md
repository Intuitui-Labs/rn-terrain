# React Native 0.84.0 — Hermes V1 Default & Node 22.11 Baseline

- **Package**: `react-native`
- **Version**: `0.84.0`
- **Release Date**: 2026-02-11
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.84.0](https://github.com/facebook/react-native/releases/tag/v0.84.0)

## 1. Summary & Architectural Context
React Native 0.84 makes Hermes V1 (with static compilation capabilities) the mandatory default JS engine, enforces Node.js >= 22.11, and adopts precompiled iOS frameworks by default.

## 2. Toolchain & Runtime Substrate Matrix
- **Node.js**: `>= 22.11`
- **React Peer Dependency**: `19.0.0`
- **Hermes Engine**: `v1.0-default`
- **Metro Bundler**: `^0.85.0`
- **Android Toolchain**: AGP `8.9.0` · Gradle `8.12` · Target SDK `35`
- **iOS Toolchain**: Deployment Target `iOS 16.0` · Xcode `16.2`
