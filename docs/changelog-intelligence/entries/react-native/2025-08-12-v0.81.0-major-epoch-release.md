# React Native 0.81.0 — Fabric ShadowNode Recycling & Web Font Metric Alignment

- **Package**: `react-native`
- **Version**: `0.81.0`
- **Release Date**: 2025-08-12
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.81.0](https://github.com/facebook/react-native/releases/tag/v0.81.0)

## 1. Summary & Architectural Context
React Native 0.81 refines iOS text rendering metrics to achieve exact 1:1 parity with CSS web font baselines and minimizes layout thrashing.

- **Node.js**: `>= 20.0`
