# React Native 0.78.0 — React 19 Concurrent Primitives & ShadowNode Recycling

- **Package**: `react-native`
- **Version**: `0.78.0`
- **Release Date**: 2025-02-19
- **Release Channel**: 🟢 GA Minor Epoch Release
- **Git Tag**: [v0.78.0](https://github.com/facebook/react-native/releases/tag/v0.78.0)

## 1. Summary & Architectural Context
React Native 0.78 stabilizes React 19 concurrent features under Fabric, hardens ShadowNode memory recycling, and tightens native event serialization.

- **Node.js**: `>= 18.18`
- **React Peer Dependency**: `18.3.1`
- **Hermes Engine**: `0.78-bundled`
- **Metro Bundler**: `^0.81.3`
- **Android Toolchain**: AGP `8.6.1` · Gradle `8.10` · Target SDK `35`
- **iOS Toolchain**: Deployment Target `iOS 15.1` · Xcode `16.2`
