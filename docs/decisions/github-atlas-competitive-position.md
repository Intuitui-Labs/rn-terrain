# GitHub Atlas Competitive Position

## Decision

GitHub Atlas will not compete as another Student Developer Pack directory or change tracker. Its role is a practical decision layer above the official catalogue.

## Existing landscape

GitHub itself provides the official Pack, Learning Paths, and Experiences. A third-party GitHub Student Developer Pack Checker tracks active/deleted offers, recent changes, date-based history, and email alerts.

These products validate the underlying problem but occupy adjacent positions:

| Product | Primary question answered |
|---|---|
| GitHub Pack | What benefits are officially available? |
| GitHub Experiences | What curated learning bundle can I follow? |
| Pack Checker | What changed in the catalogue? |
| GitHub Atlas | What should I use for my goal, given practical constraints and evidence? |

## Differentiation

Atlas combines:

- goal- and constraint-based recommendations;
- user-adjustable priorities;
- practical availability and redemption friction;
- requirements, limits, exclusions, and validity;
- advertised value versus usable value;
- source evidence and disagreement;
- explanations for recommendations and exclusions;
- sequence and dependency-aware project paths.

## Product boundary

Atlas may consume official Pack changes and GitHub Experiences, but must not imply that it is the official source. It should link back to GitHub and providers, label Atlas interpretations clearly, and preserve uncertainty when official and observed evidence conflict.

## Validation question

The project is worth continuing only if a student can make a better tool or project decision with Atlas than with the official Pack page, GitHub Experiences, or a change tracker alone.
